# Escapada. ✈️

**De las ganas de viajar al viaje organizado.**

Escapada es una aplicación para planificar viajes en grupo, desde escapadas de fin de semana hasta vacaciones largas.

## Objetivo

Ayudar a amigos y grupos a ponerse de acuerdo, tomar decisiones y organizar un viaje sin perder información en los chats.

## Funcionalidades previstas

- Crear viajes y convocar participantes.
- Proponer destinos y votar fechas.
- Organizar alojamiento, transporte y actividades.
- Llevar un checklist de pendientes.
- Estimar presupuestos y dividir gastos.
- Compartir recuerdos del viaje.

## Estado

🚧 Proyecto en desarrollo. Se construye como una aplicación independiente de **Juntada.**, reutilizando componentes y aprendizajes del prototipo.

## Privacidad

No incluyas contraseñas, credenciales, tokens ni datos personales en este repositorio público.
